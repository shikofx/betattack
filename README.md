# BetAttack

## Описание проекта

**BetAttack** — это распределенная система для сбора, анализа и автоматического совершения ставок на сайтах букмекерских контор в реальном времени. Проект построен на микросервисной архитектуре и демонстрирует full-stack подход к разработке сложных автоматизированных систем.

Система состоит из шести основных компонентов:

1. **`betattack-service-dbmanager` (Сервис управления БД)**: Бэкенд-сервис на Node.js и Express. Предоставляет REST API для централизованного управления данными (пользователи, счета, история игр) в MongoDB. Является единым источником правды для всей системы.

2. **`betattack-service-socket-server` (Сервис-координатор)**: "Мозг" системы на Node.js и Socket.IO. Оркестрирует взаимодействие между UI и сервисами-исполнителями в реальном времени, управляет очередью задач на совершение ставок и распределяет нагрузку.

3. **`betattack-service-datacenter` (Основной исполнитель)**: Бэкенд-сервис на Node.js и Puppeteer. Выполняет основную работу по парсингу **live-событий**: авторизуется на сайтах, собирает данные по ходу матча и совершает ставки по команде от сервера-координатора.

4. **`betattack-service-bet-calendar` (Сборщик календаря)**: Специализированный сервис на Node.js и Puppeteer, который парсит страницы с **предстоящими событиями** (линию) на букмекерских сайтах и сохраняет их в базу данных для последующего анализа.

5. **`betattack-service-betspy` (Удаленный исполнитель/Spy)**: Легковесный сервис-исполнитель на Node.js, который может быть развернут на удаленных машинах. Он подключается к `socket-server` и выполняет те же функции, что и `datacenter`, но с другого IP-адреса. Это позволяет горизонтально масштабировать систему и обходить ограничения сайтов.

6. **`betattack-app-desk` (Клиентское приложение)**: Десктопная панель управления на Java и JavaFX. Позволяет пользователю отслеживать события, управлять счетами и инициировать "атаки" (задачи на совершение ставок).

## Сборка и запуск

Для запуска проекта необходимо последовательно развернуть все его компоненты.

### Требования
* Node.js (v12.x или выше)
* NPM
* PM2 (`npm install pm2 -g`)
* MongoDB (локальная или облачная)
* Java JDK (v11 или выше)
* Maven

---

### 1. Запуск `betattack-service-dbmanager`

Этот сервис должен быть запущен первым.

1. Перейдите в директорию `betattack-service-dbmanager`.
2. Установите зависимости: `npm install`.
3. Настройте подключение к MongoDB. В файле `ecosystem.config.js` укажите вашу строку подключения `MONGODB_URL`.
4. Запустите сервис с помощью PM2: `pm2 start ecosystem.config.js`.

### 2. Запуск `betattack-service-socket-server`

1. Перейдите в директорию `betattack-service-socket-server`.
2. Установите зависимости: `npm install`.
3. Убедитесь, что в `ecosystem.config.js` в переменной `URL_DBMANAGER_HOST` указан корректный адрес запущенного сервиса `db-manager`.
4. Запустите сервис с помощью PM2: `pm2 start ecosystem.config.js`.

### 3. Запуск сервисов-исполнителей (`datacenter`, `bet-calendar`, `betspy`)

Эти сервисы запускаются аналогично. Для примера `datacenter`:

1. Перейдите в директорию `betattack-service-datacenter`.
2. Установите зависимости: `npm install`.
3. Настройте подключение к `socket-server` в конфигурационных файлах.
4. Запустите сервис: `node src/index.js`.
    *В полноценной среде эти сервисы также должны быть обернуты в `ecosystem.config.js` и запущены через PM2 для надежности.*

### 4. Сборка и запуск `betattack-app-desk`

1. Откройте проект `betattack-app-desk` в вашей IDE (например, IntelliJ IDEA).
2. Убедитесь, что настроен JDK 11+.
3. Соберите проект с помощью Maven (`Lifecycle -> package`).
4. Запустите главный класс `com.pkt.betattack.app.desk.App`.
5. В приложении потребуется ввести логин и пароль от пользователя, созданного в `db-manager`, для получения JWT токена и доступа к системе.
