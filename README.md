# BetAttack

## Описание проекта

**BetAttack** — это распределенная система для сбора, анализа и автоматического совершения ставок на сайтах букмекерских контор в реальном времени. Проект построен на микросервисной архитектуре и демонстрирует full-stack подход к разработке сложных автоматизированных систем.

Система состоит из четырех основных компонентов:

1.  **`betattack-service-dbmanager` (Сервис управления БД)**: Бэкенд-сервис на Node.js и Express, предоставляющий REST API для централизованного управления данными (пользователи, счета, история игр) в MongoDB.
2.  **`betattack-service-socket-server` (Сервис-координатор)**: "Мозг" системы на Node.js и Socket.IO. Оркестрирует взаимодействие между UI и сервисами-исполнителями, управляет очередью задач на совершение ставок и распределяет нагрузку.
3.  **`betattack-service-datacenter` (Сервис-исполнитель)**: Бэкенд-сервис на Node.js и Puppeteer. Выполняет "грязную" работу: авторизуется на сайтах, парсит данные и совершает ставки от имени пользователя по команде от сервера-координатора.
4.  **`betattack-app-desk` (Клиентское приложение)**: Десктопная панель управления на Java и JavaFX. Позволяет пользователю отслеживать события, управлять счетами и инициировать "атаки" (задачи на совершение ставок).

## Сборка и запуск

Для запуска проекта необходимо последовательно развернуть все его компоненты.

### Требования
*   Node.js (v12.x или выше)
*   NPM
*   PM2 (`npm install pm2 -g`)
*   MongoDB (локальная или облачная, например, MongoDB Atlas)
*   Java JDK (v11 или выше)
*   Maven

---

### 1. Запуск `betattack-service-dbmanager`

Этот сервис должен быть запущен первым, так как от него зависят остальные.

1.  Перейдите в директорию `betattack-service-dbmanager`.
2.  Установите зависимости:
    ```bash
    npm install
    ```
3.  Настройте подключение к MongoDB. В файле `ecosystem.config.js` (или в `.env` файле) укажите вашу строку подключения `MONGODB_URL`.
4.  Запустите сервис с помощью PM2:
    ```bash
    pm2 start ecosystem.config.js
    ```

### 2. Запуск `betattack-service-socket-server`

1.  Перейдите в директорию `betattack-service-socket-server`.
2.  Установите зависимости:
    ```bash
    npm install
    ```
3.  Убедитесь, что в `ecosystem.config.js` в переменной `URL_DBMANAGER_HOST` указан корректный адрес запущенного сервиса `db-manager` (по умолчанию `http://185.213.209.34:3000`).
4.  Запустите сервис с помощью PM2:
    ```bash
    pm2 start ecosystem.config.js
    ```

### 3. Запуск `betattack-service-datacenter`

1.  Перейдите в директорию `betattack-service-datacenter`.
2.  Установите зависимости:
    ```bash
    npm install
    ```
3.  Запустите сервис (в данном проекте он запускается как простой Node.js скрипт для демонстрации):
    ```bash
    node src/index.js
    ```
    *В полноценной среде этот сервис также должен быть обернут в `ecosystem.config.js` и запущен через PM2, чтобы подключаться к `socket-server`.*

### 4. Сборка и запуск `betattack-app-desk`

1.  Откройте проект `betattack-app-desk` в вашей IDE (например, IntelliJ IDEA).
2.  Убедитесь, что настроен JDK 11+.
3.  Соберите проект с помощью Maven. В IDEA это можно сделать через панель Maven (`Lifecycle -> package`).
4.  Запустите главный класс `com.pkt.betattack.app.desk.App`.
5.  В приложении потребуется ввести логин и пароль от пользователя, созданного в `db-manager`, для получения JWT токена и доступа к системе.
